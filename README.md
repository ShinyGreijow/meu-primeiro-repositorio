### 💻 Git Quick Reference (Para Iniciantes)

| Ação | Comando |
| :--- | :--- |
| **Configurar Usuário** | `git config --global user.name "Seu Nome"` |
| **Iniciar Repo** | `git init` |
| **Ver Status** | `git status` |
| **Salvar Alterações** | `git add .` + `git commit -m "mensagem"` |
| **Enviar para Nuvem** | `git push origin main` |
| **Baixar Atualizações** | `git pull origin main` |
| **Criar Nova Branch** | `git checkout -b nome-da-branch` |
